# **Unit 4: Structured Query Language (SQL)**

**Topics Covered:**

- Querying in SQL.
- DDL to create database and tables.
- Table constraints.
- Update database-update behaviours.
- DML.
- Aggregation functions.
- Group by and having clauses.
- Retrieve data from the database.
- Generate and query views.
- Access and manipulate databases using ODBC.
- Basic Database administration SQL commands.
