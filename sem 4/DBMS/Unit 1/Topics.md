# **Unit 1: Introduction to Database**

The guidelines specify that Unit 1 covers the purpose of database systems, characteristics of the database approach, data models, architecture, components, data independence, and the comparison between file systems and database systems. These topics correspond to specific sections in **Chapter 1** and **Chapter 2** of the textbook.

### **Chapter 1: Databases and Database Users**

This chapter introduces the fundamental concepts of databases, users, and the capabilities of DBMS software. The specific sections required are:

- **1.1 Introduction:** Defines databases, DBMS, and the database system environment.
- **1.2 An Example:** Provides a specific example (UNIVERSITY database) to illustrate concepts.
- **1.3 Characteristics of the Database Approach:** Distinguishes the database approach from traditional file processing (e.g., self-describing nature, insulation between programs and data).
- **1.4 Actors on the Scene:** Identifies database administrators, designers, and end users.
- **1.5 Workers behind the Scene:** Identifies DBMS system designers and tool developers.
- **1.6 Advantages of Using the DBMS Approach:** Discusses benefits such as controlling redundancy, restricting unauthorized access, and enforcing integrity constraints.
- **1.8 When Not to Use a DBMS:** Discusses overhead costs and situations where a DBMS may be unnecessary.

### **Chapter 2: Database System Concepts and Architecture**

This chapter covers the terminology, architecture, and classification of database management systems. The specific sections required are:

- **2.1 Data Models, Schemas, and Instances:** Defines data abstraction, categories of data models (conceptual, physical, representational), and the difference between database schema and state.
- **2.2 Three-Schema Architecture and Data Independence:** Explains the internal, conceptual, and external levels of architecture and the concept of logical and physical data independence.
- **2.3.1 DBMS Languages:** Covers Data Definition Language (DDL) and Data Manipulation Language (DML).
- **2.4 The Database System Environment:** Provides an overview of the DBMS software modules.
    - **2.4.1 DBMS Component Modules:** Specifically details components like the buffer manager, stored data manager, and query compiler.
- **2.6 Classification of Database Management Systems:** Categorizes DBMSs based on data models (relational, object, etc.), number of users, and sites.
